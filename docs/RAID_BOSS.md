# 薬品工場の希少ボス部隊

高脅威区域に登録した専用地点へ、ボス1人と護衛2人を1部隊として出す。通常SCAVのスポーン地点・装備抽選・再湧きとは分ける。データパック・リソースパックは変更しない。

## 出現

`raid-boss.enabled: true`、`raid-boss.map-id: ノヴォザリエ薬品工場`、`raid-boss.chance: 0.125` が既定値。chanceは0～1の有限値。範囲外では出現しない。対象マップに有効な3人分の登録がある時、新しいRaidInstanceで1回だけ抽選する。複数区域の登録があっても、候補から1区域を選び、マップ全体で最大1部隊。参加者ごと・接近ごとの抽選はしない。

当選しても、3地点すべてが安全になるまで生成を待つ。少なくとも1人がいずれかの地点から64ブロック未満へ接近し、観戦者・銃用FakePlayer以外のワールド内プレイヤー全員について、3地点とも24ブロック以上離れ、80ブロック未満で足・胴・頭のいずれにも視線が通っていないことを確認する。既存のSCAVスポーンと同じ視認判定を使用する。3地点のチャンク、頭・肩の空間と足場を実際のブロック形状で確認する。未読込チャンクをロード・生成しない。

スポーンを試す直前に抽選権を消費する。1人でも銃・必須装備・弾の生成に失敗した時は、それまでに生成した部隊員を削除し、同じレイドでは再試行しない。倒した後の再湧きや、プレイヤーが離れてから戻った時の再生成もない。出現した部隊は通常SCAVの距離デスポーン対象に入れない。レイド終了・周期リセット・サーバー停止で全員を回収する。

ボス部隊のMob自体も永続化しない。再起動で途中のレイドを復元する場合、ボスの抽選・再生成を抑止する。倒した部隊や使われた装備の復活を避けるため、当選待ちや生存中だった部隊もその継続レイドでは復元しない。次の新規レイドから再び抽選する。

## 地点登録（OP）

最初に `/raid danger list ノヴォザリエ薬品工場` で区域IDを確認する。高脅威区域がまだ無ければ、WorldEdit/FAWEで選択して `/raid danger add <mapID> <zoneID> [表示名]` で登録する。

その区域内の、安全な足場のある3地点にそれぞれ立って実行する。

```text
/raid boss set ノヴォザリエ薬品工場 <zoneID> boss
/raid boss set ノヴォザリエ薬品工場 <zoneID> guard1
/raid boss set ノヴォザリエ薬品工場 <zoneID> guard2
/raid boss list ノヴォザリエ薬品工場
```

護衛2人はボスの左右、遮蔽のある位置などへ手動配置する。地点間は1.5ブロック以上、護衛はボスから12ブロック以内。3地点が揃い、全員が区域内に収まった登録だけ抽選対象。listは未登録・区域外・間隔不足も表示する。登録・削除・configの変更は次の新規レイドへ適用する。

`/raid boss remove <mapID> <zoneID>` はその部隊の地点だけを削除する。区域自体は残す。`/raid danger remove` で高脅威区域を削除した場合は、対応する部隊地点も削除する。地点は既存のマップJSONへ保存する。旧JSONのbossGroups未定義・nullは空として扱う。configのmap-idを変更した場合、出現対象もそのIDへ切り替わる。

## 装備と戦闘

| 役割 | 銃 | AI |
|---|---|---|
| ボス | SCAR-H | HIGH |
| 護衛1 | M4A1 | MID |
| 護衛2 | AS VAL | MID |

全員Altyn（頭・顔、クラス4）、SP-V（胴・腕、クラス5）、Pilgrimを装備する。防具と銃は生成時は完品。弾はそれぞれの口径で貫通クラスが最上位のもの、同クラスなら威力の高いものを選ぶ。予備は3マガジン分。通常SCAVのプレイヤー防具に応じた弾薬クラス上限とクラス4防具の出現数制限には混ぜない。体力40・移動速度は通常SCAVと同じ。通常のLOW/MIDスポーン比率も変えない。

部隊内だけで既存の視認共有・援護を使う。ボスは援護役、護衛は前衛役を維持し、通常SCAVとは役割・救援を組まない。登録した左右の配置を基準に行動し、固定隊列を常に維持する追従AIではない。

ボスは登録地点の水平8ブロック、護衛は各登録地点の水平12ブロック、高さ差6ブロックまでを持ち場とし、さらに高脅威区域の境界で制限する。AI更新の前後で、現在位置・経路の未消化地点・直接移動先・ピーク先を確認する。範囲外の追跡・音への捜索・巡回等を中断し、元の地点へ歩いて戻る。帰還中は発射を止め、瞬間移動は行わない。持ち場内から区域外の相手を撃つことは可能。物理的なノックバックや経路指示後の移動を完全に囲い込む境界ではない。戻る経路が無い場合や、区域端の狭い通路は実地調整する。

装備を報酬にする。死亡時は既存の死体生成へ実装備・銃の残弾・残った予備弾を渡し、戦闘で減った耐久を回復しない。ボスだけHIGHとして既存のBOSSキル集計へ入り、護衛はSCAVキルになる。SP-Vは現在のラグドール部位モデルの対応外なので、この装備の死体は従来通り通常Mannequin表示へフォールバックする。

## 検証と実機確認

RaidBossPolicyTestは一度だけの抽選、12.5%境界、復元・無効設定、旧JSON、登録の複製防止・区域と間隔、持ち場の範囲、部隊生成途中の失敗回収を確認する。RaidBossSpawnSafetyTestは足場・頭上・肩の障害物・未読込チャンク・液体・世界の高さを確認する。ScavBossAmmoTestは実際の弾カタログからの口径別最上位選択と、弾未定義での生成拒否を確認する。既存の照準、ピーク、判断安定性、射線回復、音の境界も確認する。

実機では3地点登録後、検証用にchanceを1にした新規レイドで生成を確認し、その後0.125へ戻す。目の前湧き、3人の連携、区域外への誘導、死体からの装備・残弾回収、討伐後の再湧きなし、レイド終了時の清掃を確認する。生のマップ座標・管理サーバー情報はこの文書へ記載しない。
