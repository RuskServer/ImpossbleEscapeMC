# 共通の移動倍率

プレイヤーとSCAVの徒歩・ダッシュの調整値は、`src/main/java/com/lunar_prototype/impossbleEscapeMC/modules/movement/MovementTuning.java`の`MULTIPLIER`に集約する。現在は`0.8`（従来から20%低下）。今後はこの正の有限値を変更してビルド・サーバー再起動する。`1.0`なら共通減速なし。各システムの基準値を個別に0.8倍し直す必要はない。

## 適用先

- プレイヤー：`MovementModule`が移動属性へ独立した`MULTIPLY_SCALAR_1`補正を適用する。重量・疲労などの既存補正や基本値を変更せず、その計算結果へ0.8倍が掛かる。ログイン・復活・有効化時のオンラインプレイヤーに適用し、切断・無効化時は自分のキーだけ外す。同じ補正は重複追加しない。
- SCAV：通常個体・護衛・ボスを作る共通スポーン処理で、基礎属性0.15に同じ補正を適用する。現在の実効値は0.12。巡回・追跡・経路移動・退避にも反映される。銃用FakePlayerはプレイヤーモジュールの対象外とし、動くSCAV本体へ一度だけ適用する。
- 戦闘横移動・ピーク：固定のネイティブ速度上限0.08と加速量0.005にも共通倍率を適用し、現在は0.064と0.004。実際の属性への補正と固定上限の補正で二重に0.8倍にならないよう、経路側の移動倍率は変えない。移動完了判定の速度しきい値と、顔出し・戻りの距離に応じた時間猶予も追従する。
- スポーン配置診断：設定の走行5.6・歩行4.3は倍率適用前の基準値として保持し、`StaminaModule.diagnosticTravel`で重量補正と共通倍率を一度だけ適用する。現在の無負荷基準は4.48／3.44ブロック毎秒。設定を先に0.8倍すると二重減速になるため、そのまま使う。

## スタミナと範囲

スタミナ消費・回復・待ち時間・ジャンプ消費は従来のまま。満タンで走り続けられる時間は変わらず、その間に進める距離が短くなる。診断では新しい速度と既存の消費・回復条件から移動時間を計算する。

共通倍率は移動属性とAIの速度制御を対象とする。外力・ノックバック、ジャンプの高さ、飛行速度、乗り物などの物理全体を書き換えるものではない。射撃・反応時間や休止時間にも適用しない。

## 検証

`MovementTuningTest`で重量・疲労・ダッシュとの乗算、重複適用防止、他の補正を残した解除を検証する。`StaminaTravelModelTest`で診断速度の共通倍率と、消費・回復量・待ち時間が維持されることを確認する。SCAVの移動上限・切り返し・顔出し往復・遮蔽判定・退避経路の回帰テストも実施する。実機では装備の軽重、スタミナ切れ、再ログイン・復活、SCAVの追跡・退避・ピークを確認する。
