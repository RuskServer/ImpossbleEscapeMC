# SCAV の判断と移動の安定化

- 交戦距離は武器の `preferredRange` × 生成時の個体差（0.75〜1.30）とする。判断周期・視認切れで引き直さず、武器が変われば次の判断から新しい距離を使う。
- 制圧状態は生の制圧値が **0.60 以上で開始、0.35 以下で解除**。減衰前にも確認し、ヒット直後の閾値越えを取りこぼさない。通常の制圧による遮蔽検索・戦術助言・恐怖加算・退避中の横移動は同じ状態を使う。
- 生の制圧値や距離は平滑化しない。射撃精度、感情・Utility の連続評価、重度制圧（0.8）や再交戦の安全条件は従来どおり生の値を使う。
- 通常移動は Controller の恐怖・戦術による上書きも含め **15 サーバー tick（0.75秒）** 維持する。被弾、弾切れ、急な制圧・パニック、デバウンス後の視認変化など既存の割り込みは維持時間を無視する。射撃判断はこの維持時間の対象外。
- 専用の退避経路、立ち位置、補給、援護、遮蔽への移動は引き続き優先し、通常移動の保持を破棄する。顔出し動作中も判断は1ステップに1回行い、被弾・弾切れなどの緊急割り込みやリロード退避なら動作を中断する。
- 同じ移動が履歴に多いという理由だけで別の行動へ変える処理を削除。横移動も区間の途中で無作為に方向を逆転させず、区間更新時だけ方向・半径・小休止を選ぶ。壁・足場の安全確認は毎回続ける。

`ScavDecisionStabilityTest` は閾値付近の連続入力、移動の維持と緊急割り込み、経路移動後の解除、武器変更と交戦距離の固定を確認する。実サーバーでは近距離の撃ち合い・連続ニアミス・顔出し中の被弾／弾切れを確認する。
