# 銃声によるSCAVの集合範囲

`config.yml` の `scav-hearing` で調整する。距離は3次元の直線距離。

| 音源からの距離（初期値） | 反応 |
|---|---|
| 32m以内 | 元の配置場所の範囲内なら捜索・接近 |
| 32m超〜64m以内 | 警戒と振り向きのみ |
| 64m超 | 銃声通知を無視 |

`gunshot-investigate-radius` は内側、`gunshot-alert-radius` は外側。外側は最大128m、内側は外側以下に制限する。通知側とSCAVの受信側で同じ設定を使う。

遠方の銃声では敵の推定位置・音の捜索先を作らず、捜索時間も延長しない。既にある交戦の記憶や捜索先を遠方の音へ置き換えない。警戒反応は1秒に1回まで。

## 音だけの捜索の移動上限

`sound-home-radius` の初期値は40m。現在地と音源が共に元の配置場所からこの範囲に入る時だけ、銃声を捜索へ使う。近くの別の銃声へ乗り換えても、基準点は動かない。

音だけで捜索している間は次を確認する。

- 現在位置と、音の誤差・足音の先読み・推定更新でできた捜索先
- 経路の残りの各地点（目的地が範囲内でも、迂回路が範囲外なら中止）
- 直接移動と顔出し動作の移動先

範囲を越える場合は、音由来の捜索・推定・移動・顔出しを解除する。既に外へ出ていた場合はホームへ戻る経路を指示する。判断はAIの更新間隔（3tick）で行うため、押し出し等で境界を少し越えた後に戻る場合がある。範囲外の経路を連射のたびに再探索しないよう、40tickは新しい音捜索を抑制する。

足音の従来の可聴範囲・壁による減衰は維持し、音だけの移動には同じホーム範囲を適用する。SCAV自身の銃声は引き続き警戒通知だけで、味方の位置を敵の捜索先にしない。

## 交戦と援護

自分で視認した相手、被弾で得た相手の情報、人数枠を使って受理した援護は通常の交戦・救援として扱う。近距離の音が鳴っても、それらを音だけの捜索へ格下げしない。援護へ切り替える時は古い音由来の捜索を解除する。

援護の人数枠は変更しない。32m以内・ホーム範囲内に密集した複数SCAVが独立に音を調べることはあるため、戦闘全体の人数を固定する機能ではない。

境界による捜索停止はAIログの`SOUND_INVESTIGATION_STOP`（`HOME_BOUNDARY`）に記録する。遠方の警戒は`DISTANT_GUNSHOT`。`ScavSoundPolicyTest`で32m・64m・40mの境界と、段階的な誘導・推定先・迂回路の範囲外判定、設定値の整合性を検証する。実際の捜索・交戦への切替と地形上の挙動はゲーム内で確認する。
