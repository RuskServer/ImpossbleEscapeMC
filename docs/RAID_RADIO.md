# クライアントの日本語無線と高脅威区域の通知

クライアントの終盤無線2本（撤収警告、EMPで途切れる連絡）を日本語にする。国連軍のロシア語放送と傍受音声は従来どおり。

生成はオフラインで行い、ゲーム中はリソースパックのOGGを再生する。Qwen3-TTS VoiceDesignで自作した男性声をBaseで再利用し、4本の話者を揃えた。以前の低さ・渋さを持つ男性声を参照した試聴twoを採用し、比較時と同じラウドネス調整（-20 LUFS、true peak -1 dB）を適用する。実在人物や既存ゲームの録音は参照していない。モデルのライセンスはApache-2.0。既存の送受信音・帯域制限・歪みの加工を使う。モデルのライセンスと生成音声の権利は別に扱う。

## 高脅威区域を登録する

対象マップのワールドでWorldEdit/FAWEの直方体選択を使う。

```text
//wand
（2点を選択。Y範囲もそのまま使用する。必要なら //expand vert）
/raid danger add <mapID> <区域ID> [表示名]
/raid danger list <mapID>
/raid danger remove <mapID> <区域ID>
```

- OP専用。区域はマップのJSONの `highThreatZones` に保存する。同じIDは上書きせず拒否する。
- 登録・削除は実行中のレイドにも反映する。初期の区域は空で、既存のマップには移行作業不要。
- 直方体以外の選択や、選択未完了、対象と異なるワールドは拒否する。WorldEdit/FAWEがない場合も説明を出す。
- 区域に1秒留まると通知。現在いる区域から横2m・上下0.5mまでは退出扱いにせず、境界の揺れを抑える。退出後の再通知は60秒以上空ける。
- コンパス直下に12フレームの警告を表示する。開く→保持→フェードアウトで計5秒。フォントはlore/HUD共通のUnifont + Monocraft。
- 区域名はチャットにも表示する。現在の敵人数や位置を読まず、事前登録した危険区域への侵入だけを知らせる。安全の保証や敵位置の通知はしない。

## タスク品の発見

SearchGUIの検索が完了して実際に見えた品、検索済みスロットから実際に取得した品、地面から拾った品を対象とする。進行中の未達成納品目標に使用できる品なら「それが探してたものだ。なくさずに持って帰ってくれ」と通知する。未検索のスロットや周囲のアイテムから情報を取らない。

コンテナ品は取得時にFIR判定を受けるため、コピーに既存の `ItemFactory.applyFIR` を適用して取得後の資格を確認する。実際の品やFIR設定、移動・保存処理は変更しない。持込品・支給品などのFIR除外は既存処理に従う。

同じ品の種類は1レイド中1回、発見無線全体で30秒の間隔を設ける。同じレイドへの再接続でも発見済みの種類を保持する（サーバー再起動をまたぐ永続化はしない）。検索完了の効果音から約0.9秒空け、複数の発見は短い汎用通知にまとめる。区域の無線と重ねずに待ち、古くなった通知は破棄する。取得済みを断定する台詞ではない。

## 音と表示の優先順位

終盤の撤収・EMP無線は、新しい区域・発見無線を中断して優先する。脱出・死亡・切断時は新しい無線と警告表示を止め、レイド終了時に状態を破棄する。音は対象本人だけに再生する。

`raid-radio.enabled: false` は追加の区域・発見無線と区域表示を停止する。従来の終盤演出の有効性とは別。

```text
/raid radio preview zone
/raid radio preview item
```

OPがレイド参加中に見た目・音を確認できる。区域の登録やクエストの進捗は変えない。

## リソースパックの生成

別リポジトリの `tools/japanese_radio.py`、`tools/japanese_radio_profile.json`、`tools/japanese_radio_manifest.json` に生成手順、話者指定、使用revision・seed・台詞・長さを記録する。モデル・キャッシュは作業用フォルダに置く。自作参照音声と採用テイクはパックの `tools/audio_sources/` に保持する。`tools/radio_alert.py` が画像・フォントと指定した作業用フォルダのGIFを生成する。

日本語EMP無線の通信断は開始から83 tick。チャットの雑音もこの位置に合わせる。音声を再生成して長さが変わったら、manifestの `static_after_voice_start_ticks` と `RaidEndSequence.STATIC_MESSAGE_DELAY_TICKS` を合わせる。

採用twoは以前の自作参照（VoiceDesign seed 211）から話者特徴だけを取り出し、Baseの `x_vector_only_mode=true`、`non_streaming_mode=true`、temperature 0.9で生成する。警告とタスク品発見は実際の試聴テイクを保持する。4本の採用テイクを `tools/audio_sources/` に固定し、再書き出しで話速・ピッチ・抑揚を変えない。素材のSHA-256と生成seedは話者プロファイルの `performance_overrides` に記録する。

## 検証

`RaidRadioStateTest`、`RaidRadioZoneTest`、`RaidRadioHudTest` は重複と優先順位、区域境界・再入場、マップ保存互換、12フレームの表示がコンパス・時間・操作ヒントの配置を変えないことを確認する。実ゲームではリソースパック更新後に区域の出入り、検索・発見、死亡／脱出中の音停止、終盤無線による割り込みを確認する。

既存 `RaidHudTest` は操作ヒントの古い幅（79/88/118）を使っているため `hint changes strip width` で変更前のRaidHudでも失敗する。現アセットとコードは78/91/113。今回その既存テストは変更せず、追加したHudテストで区域表示と現行ヒントの併用を検証する。
