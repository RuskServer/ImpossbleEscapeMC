# バイザーの顔面防護

FAST-MT用バイザーは顔面クラス2・専用耐久300を持つ。FAST-MT本体は頭部クラス3のままで、クラスは加算しない。PVS-14には防護クラスがなく、装着しても顔面を守らない。Altynの一体型バイザーは既存どおり顔面・頭部クラス4、本体と共通の耐久を使う。

## ダメージと消耗

`BulletDamageModel.armorPiece` が命中部位に対応する防具を選ぶ。取り付け型バイザーは対応ヘルメットに装着されていて、顔面に命中した場合だけ候補になる。弾薬クラスによる既存の貫通判定、耐久による有効クラスの低下、貫通時の軽減、顔面の頭部ダメージ倍率をそのまま使う。旧バイザーの跳弾抽選と跳弾率表示は廃止する。

阻止時は3、貫通時は既存のダメージに応じた耐久消費を適用する。顔面被弾では取り付け型バイザーだけ、頭部被弾ではヘルメット本体だけを消耗する。プレイヤーとSCAVで共通。耐久0のバイザーは防護せず、本体の頭部クラスを顔面に代用しない。壊れても装着状態・見た目・画面効果は維持し、取り外し・交換できる。

## 保存・旧アイテム

バイザーの残耐久は`visor_durability`の整数PDCとして、単体アイテムまたは装着先ヘルメットに保存する。本体の`durability`とは独立している。キーのない旧単体・旧装着済みバイザーは満タンとして扱う。旧単体アイテムの一般耐久が0でも、バイザー破損とは解釈しない。明示的な専用耐久0は破損状態を維持する。

アタッチメント画面で取り付ける時は実物の専用耐久を読み、外す・交換する時は残耐久を単体アイテムへ戻す。単体・ヘルメット・装着画面にクラスと残耐久を表示する。ヘルメット本体の修理では専用耐久を回復しない。

## 検証

`VisorArmorTest`でカタログ、防具選択、FAST-MTとPVS-14の顔面防護差、旧アイテム、破損、顔と頭の消耗先、Altyn一体型防護、共通ダメージ計算を確認する。アイテム/PDCとレジストリはテスト用の代用品を使う。実サーバーでは古いアイテムへの適用、装着・交換・取り外し前後の残耐久、プレイヤー/SCAVの顔・頭への実射、表示と効果を確認する。
