# スキルツリー 設計案

隠れ家の設備「スキルツリー」(`HideoutFacility.SKILL_TREE`, 最大 Lv3) から開くダイアログで、
**お金 (₽) と素材を払ってノードを 1 つずつ習得する**。ノードにランク (段階強化) は無く、1 ノード = 1 効果。
効果はすべて **今あるゲームの仕組みの数値をいじるだけ** (新しい仕組みは足さない)。

数値・費用はすべて仮。実装時は 1 か所 (スキルの定義) にまとめて、後から調整できるようにする。

---

## 1. 仕組み

### 習得の条件
| 条件 | 内容 |
|---|---|
| ティア | 設備のレベルで開く。設備 Lv1 → ティア I、Lv2 → ティア II、Lv3 → ティア III |
| プレイヤーレベル | ティア I: なし、ティア II: Lv5、ティア III: Lv10 |
| 前提ノード | ティア II 以降は、線でつながった前のノードを習得済み (ティア III は 2 つ) |
| 費用 | ₽ + 素材。素材は隠れ家の設備と同じく、手持ち + スタッシュ全ページから取る (FIR 不要) |

- スキルポイントは無し。お金と素材がそのまま「ポイント」の代わり。
- 習得は取り消せない (振り直しは今回は入れない。必要なら後で決める)。

### 費用の目安
相場はブローカーの買取値 (`TraderCatalog`)。設備 Lv1 の費用が約 50,000₽ 相当 (工具箱・小型バッテリー×3・ボルト×4・USB)。

| ティア | ₽ | 素材 (買取値の合計) | 1 ノードの合計 |
|---|---|---|---|
| I | 6,000〜12,000 | ガラクタ・工具 (3,000〜6,000) | 約 1 万〜1.8 万 |
| II | 20,000〜40,000 | 電子部品・医薬品・工具箱 (8,000〜20,000) | 約 3 万〜6 万 |
| III | 70,000〜100,000 | 貴重品 1 つ + 中位の素材 (40,000〜130,000) | 約 12 万〜23 万 |

1 系統 (17 ノード前後) を全部取ると約 100 万₽ 相当。S ランク (純利益 25 万₽) のレイド 4 回分くらい。

### 素材の使い分け (系統の雰囲気に合わせる)
| 系統 | 主な素材 |
|---|---|
| 射撃 | ボルト・ドライバー・レンチ・工具箱、弾薬 |
| 体力 | 固形燃料・浄水フィルター・トイレットペーパー |
| 医療 | CAT・AI-2・浄水フィルター |
| 隠密・探索 | フラッシュライト・小型バッテリー・スクラップ・USB |
| 交易 | シガレット・USB・グラフィックボード・機械式金時計 |

## 3. 画面 (ダイアログ) への影響

プレビュー (`IEM_shader/preview/skill_tree_*.png`) からの変更:
- ランクの目盛りを無くし、ノードを小さく (18 マス程度) して **5 列 × 5 段** に並べる
  (ティア I が 2 段・ティア II が 2 段・ティア III が 1 段。1 系統 25 ノードまで入る)。
- 上の札の液晶は「ポイント」をやめて **所持金** にする。
- 右の詳細の下は「必要 1 ポイント」をやめて、隠れ家の設備と同じ **₽ と素材の行** (持っている数 / 必要数、足りないものは赤)。
- 系統のタブは 5 つ (射撃・体力・医療・隠密・交易)。

## 4. 実装

| 物 | 場所 |
|---|---|
| ノードの一覧 (この表と同じ。数値・費用を変える時は両方) | `modules/skill/SkillCatalog.java` |
| 習得・効果の値 (`SkillModule.value(player, SkillStat)`) | `modules/skill/SkillModule.java` |
| 画面 (ダイアログ) | `modules/skill/SkillTreeDialog.java`。隠れ家のスキルツリー設備のブロックを右クリックで開く |
| 画面の絵 (フォント iem:skill) | `IEM_shader/tools/skill_font.py`・`skill_icons.py` |
| 保存 | `PlayerData.skills` (習得したノードの id) |
| 確認 | `SkillTreeDialogLayoutTest` (行の幅・線がノードを通らない/交わらない)。`IEM_DIALOG_DUMP` で `dialog_render.py` の見本 |

習得の流れは隠れ家の設備と同じ: 条件 → お金を取る → 素材を取る (取れなければお金を返す) → 保存。

### 効果の差し込み先
| 系統 | 場所 |
|---|---|
| 射撃 | プラグインが倍率を `toisarm.mod.<名前>` のスコア (千分率) に置き、データパック (Tois-Armory-Dev) の `toisarm:player/load_gun_data/get/modifiers` が銃を読み込んだ時に掛ける。次に銃を持ち替えた時から効く。アニメーションは時間に合わせて伸び縮みする |
| 体力 | `StaminaModule` (上限は減り方・回復を割って表す)、`SkillModule.weightStage` (「軽い」の上限)、`WeightModule` (走れなくなる重さ・遅くなる重さ) |
| 医療 | `StatusEffectManager` (出血・骨折・自動の痛み止め)、`MedicalModule` (CAT の時間・AI-2 の回復と間隔と耐久・中断の猶予) |
| 隠密・探索 | `SearchGUI` (1 tick ごとに進むようにした)、`PlayerListener` (足音・気づかれるまで・範囲・草の音)、`ScavVision`、`RaidInstance` (脱出)、`GroundItemService` |
| 交易 | `TraderModule.buyPrice` / `dailyLimit` / `sellMultiplier` / `repairMultiplier` (トレーダーの画面の表示も同じ値)、`SupplyLoadout`、`RaidInstance` (レイドの経験値の上乗せ。リザルトの内訳に「スキル (記録係)」) |

## 5. 決めたこと (仮の値で実装。後から調整)
1. 設備 Lv2 = 工具箱×2・浄水フィルター×2・レンチ×4・USB×2、Lv3 = グラフィックボード×1・工具箱×3・小型バッテリー×6・機械式金時計×1
2. ティア II / III のプレイヤーレベルは Lv5 / Lv10
3. 振り直しは入れない
4. 素材に FIR は求めない (隠れ家と同じ)

ツリーの線は「親の下の隙間で横に曲がり、子の列を下りる」ので、線がノードを通らないように前提を一部変えた
(体力の担ぎ手 = 11, 12、医療の手早い処置 = 1 のみ、隠密の影に溶ける = 4, 10)。
