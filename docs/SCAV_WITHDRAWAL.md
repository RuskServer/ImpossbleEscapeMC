# SCAVの撤退経路

負傷・リロード・WITHDRAWモードの撤退では、通常の立ち位置選びより専用のScavWithdrawalを優先する。敵の既知位置だけを使う。

- 半径2・4・8・12・16m、12方位の候補から、立てる地点を探す。高さは現在の足元から±3ブロックまで。
- 頭と胴の中心から既知の敵位置へ射線が通らない地点を遮蔽とする。現在位置が既に遮蔽ならその場を維持する。
- 遮蔽候補6件、非常用の露出した退避候補2件までPaperの経路を確認する。到達可能な遮蔽を優先し、遮蔽が使えない時だけ敵から遠ざかる非常用退避を使う。
- 実際の経路を約1m間隔で調べ、最初に射線を切るまでの距離、露出距離、遮蔽後の再露出、実経路長、危険マップ、敵へ近づく量を減点する。退避方向が1方向以下の行き止まり候補も減点する。
- 評価した経路を移動に使う。すぐ隣（4m以内）の遮蔽に直進できる時は相手を向いて直接移動し、それ以外は小走りで経路を進む。近距離だからという理由で撤退をやめて撃ち合う処理には入らない。
- 選んだ経路はモード期限が切れても移動中は維持する。経路の残距離が24tick改善しない、移動開始失敗、目的地が塞がれた・露出した、160tickの移動上限に達した時は選び直す。失敗した地点は80tick候補から外す。
- 見失った時の捜索や追跡で撤退経路を上書きしない。敵の記憶の寿命は進める。
- 到着して実際に隠れた後は停止して備える。再交戦には既存の待ち時間・武器準備・弾数・体力・制圧・直近被弾の条件を使う。
- 使える経路がない、または探索待ちの間は、射撃と従来の回避行動を続ける。

候補探索は全SCAVで同じtickに1体まで。1回の経路評価は8件、各経路40mまで。無制限の経路探索やチャンク読込は追加しない。敵の肩が見えるような部分遮蔽、複数の敵からの同時射線、扉を開けた後の状態、16mより遠い遮蔽を完全に評価するものではない。目的地が後から露出すれば選び直す。

`WithdrawalRouteCostTest` は、短い露出経路より早く射線を切る迂回路を選ぶ配点、再露出・危険・敵への接近・行き止まりの減点、進捗停止と移動期限を検証する。実ワールドでの射線・移動・負荷はゲーム内で確認する。
