# レイド背景音のミックス

背景音は足音・銃声・操作音の後ろに置く。素材は既存の6種類（ステレオ、4秒、先頭と末尾0.5秒フェード）を使用し、`AmbienceService`で再生ゲインを調整する。雨は従来どおりバニラに任せる。

| 背景 | 再生倍率（旧1.0） | 旧比 |
| --- | ---: | ---: |
| 屋外・昼／夜 | 0.40 | 約−8.0dB |
| 屋内・昼／夜 | 0.50 | 約−6.0dB |
| 広い屋内 | 0.45 | 約−6.9dB |
| 地下 | 0.35 | 約−9.1dB |

屋外の鳥・虫、地下の唸りを含む背景を追加で抑える。素材内の音を個別に分離・加工する方式ではなく、背景全体のゲイン調整である。素材側で付いている屋内外の音量差も引き続き有効。

## 切り替えと終了

場所・昼夜の判定は10tickごと、切り替え候補は連続2回で確定する。最初の背景はすぐ再生するが、その後の切り替えは次の切れ端の開始時刻（前の開始から70tick、通常TPSで3.5秒後）に合わせる。新しい場所が確定しても、現在の切れ端の末尾フェードまで待つ。急に新旧の背景を長時間重ねず、通常ループと同じ0.5秒だけクロスフェードさせる。候補確定が境界に間に合わなければ、次の境界まで現在の背景を継続する。

更新が遅れても取りこぼした切れ端をまとめて再生しない。脱出・死亡・観戦移行では、現在の背景と残っている直前の背景をイベント名＋AMBIENTカテゴリで止める。他の効果音、雨、レイド終了演出の音は停止対象にしない。

## 検証

`AmbiencePlaybackTest`で再生ゲイン、候補の確定待ち、切り替え時刻、頻繁な出入り、更新遅延、最大2本のフェード重なり、終了時の停止対象を検証する。フェードの検証は生成素材と同じ形の正規化包絡を使い、実音源の聴感評価ではない。`AcousticsTest`で既存の場所・昼夜分類も確認する。実機では静かな屋内、屋外の鳥や虫、地下、出入口、脱出後のリザルトで音量と切り替えを確認する。
