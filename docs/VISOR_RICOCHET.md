# バイザーの跳弾

FAST-MT_visor の `VisorStats.ricochetChance = 0.10`。対応ヘルメットに装着して頭に装備した時だけ有効。
頭部への銃弾を、頭の向きに対して水平の正面左右60度以内から受けた時、貫通判定より先に一度抽選する。
跳弾時はダメージと BulletHitEvent による負傷判定を発生させず、衝突音を鳴らしてその弾の処理を終える。
弾を物理的に反射して別の対象へ飛ばす処理、角度別の確率、専用耐久は追加していない。

プラグイン銃は BulletTask、データパック銃は DatapackBulletHitBridge から共通判定を呼ぶ。
データパックのファイルやリソースパックは変更しない。処理中の弾Markerの方向をプラグインが読む。
入射方向を確定できない時は跳弾なし。データパック自身が出す着弾演出はそのまま。
既存アイテムでも装着PDCがあれば有効。バイザー説明に正面頭部の跳弾率を追加。

変更クラスのコンパイルと VisorRicochetTest の正面・背面・側面・胴・垂直・確率境界を確認。
サーバー実機での被弾試験は未実施。
