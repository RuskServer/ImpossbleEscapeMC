# パーティーと隠れ家

パーティーに所属しているプレイヤーが隠れ家に入ると、リーダーの隠れ家の区画に集まる。設備の利用 (クラフト・スキルツリー・スタッシュ・強化) はクリックした本人のデータで判定されるので、どの隠れ家にいても自分のレベルのまま。実装は `HideoutModule` (`src/main/java/com/lunar_prototype/impossbleEscapeMC/modules/hideout/HideoutModule.java`)。

## 集まる先

- `/hideout visit` と PDA ホームの「隠れ家へ移動」は `HideoutModule.visit` を通る。案内先は `visitHost` で決める: パーティーに所属していてリーダーでなければリーダー、リーダー自身と所属していない人は自分の隠れ家 (今まで通り)
- リーダーがオフラインでも案内する。リーダーのプレイヤーデータはディスクから読めて (`PlayerDataModule`)、区画の割り当て (`assignSlot`) と建築 (`ensureBuilt`) はオンラインの時と同じ
- 建ちている建物はリーダーの設備レベルの物。メンバーは自分のレベルで設備を使う (下)
- パーティーはメモリだけ (再起動で解散) なので、再起動後は全員が自分の隠れ家に入る

## 設備の判定

- 「どのブロックがどの設備か」(`facilityAt`) は、クリックしたブロックの x 座標から区画を求め (`HideoutModule.slotAt`、`SLOT_STRIDE` = 1000 ブロック間隔)、その区画の持ち主のレベルで判定する。持ち主は台帳の逆引き (`HideoutSlots.ownerOf`) で調べる
- 開いた先の画面 (`CraftDialog`・`SkillTreeDialog`・`StashPageSelectorGUI`) はクリックした本人の `PlayerData.hideoutLevels` でレベルを判定する。リーダーの隠れ家にいても自分のレベル基準で使える。リーダーが持っていない設備は物理的に無いので使えず、自分が持っていない設備はレシピがすべて鍵のかかった状態で開く
- 効果系も各自: 集水設備の空腹の軽減 (`foodDrainMultiplier`) は本人の WATER レベル

## 強化とカメラ

- 設備の管理画面 (`HideoutDialog`) は、隠れ家のワールドにいればどこでも開ける。強化は常に**自分の**隠れ家の区画に対して行われる (立ち位置に関係なく `origin(自分の hideoutIndex)` に差分を適用する)
- カメラ (スペクテイターの設備プレビュー) は自分の区画に立っている時だけ出る。ほかの人の区画にいる時はカメラなしのダイアログになる
- パーティー中のメンバーは物理的には自分の隠れ家に戻れない (visit は常にリーダーの隠れ家)。自分の区画に立つ必要があればパーティーを抜ける

## 試験

`HideoutVisitTest` で案内先 (`visitHost`: メンバー→リーダー、リーダー・パーティー無し・部外者→null) と区画の計算 (`slotAt`: 1000 間隔と負の座標) を確かめる。サーバーでは、パーティーを作ってメンバーが `/hideout visit` でリーダーの区画に飛ぶこと、リーダーの設備をクリックして自分のレベルでクラフトができること、リーダーがオフラインのままでもメンバーが入れることを確認する。
