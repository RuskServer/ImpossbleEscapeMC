# 薬莢の拾得演出除外とアドレナリンの心拍終了音

## 薬莢

Tois Armoryの`toisarm:util/ejection/`は、薬莢をitemエンティティとして生成し、`toisarm.casing`タグとPickupDelay 32767を設定する。旧GroundItemServiceは視線の先のitemを区別せず、拾えない薬莢まで拾得対象の縁取り・寝かせ表示に含めていた。

GroundItemEligibilityで、薬莢タグ、永久拾得待ち（32767以上）、プレイヤー拾得不可のアイテムを除外する。生成時の監視、再走査、各tickの継続監視、視線判定、手動拾得直前で同じ判定を使う。途中で対象外になった場合は、このプラグインが作った見た目だけを戻して監視から外す。レイキャストの候補から薬莢を外すため、その奥の通常アイテムも対象にできる。普通のドロップの短い拾得待ちや汎用THISタグは除外しない。材質を一括除外しないので通常のblaze_rod等も扱える。

必要素材のエンチャント光・Loreを付ける処理は今回変更しない。Tois Armoryのデータパックも変更しない。

## アドレナリン終了時

ScreenEffectServiceのアドレナリンのフェード段が自然に終わった時、AdrenalineHeartbeatRecoveryで約4秒の心音の余韻へつなぐ。既存のWARDEN_HEARTBEATを本人にだけ鳴らし、拍の間隔を10→20tickへ広げ、音量を下げ、ピッチも少し落とす。実際に最後に鳴った拍からの間隔を引き継ぐので、終了境界で重なって鳴らさない。

余韻は音だけで、鎮痛の持続時間・効果・クールダウン・画面効果の持続時間は延長しない。新たなアドレナリンや他の演出、死亡、余韻中のワールド移動、退出では停止する。瀕死の出血状態は既存の心音を優先し、回復用の余韻を重ねない。クリエイティブ・観戦・読み込み待ちでは余韻を継続しない。

StatusEffectManagerは自動アドレナリンで設定した満了時刻を区別し、その満了時のBEACON_DEACTIVATE音を鳴らさない。鎮痛終了のテキストは維持する。他の満了時刻であれば従来の鎮痛終了音を維持する。自動効果の識別情報は死亡・退出で破棄する。心音の余韻は画面演出の自然終了に従うため、読み込みで演出の進行が止まる場合は壁時計の鎮痛満了時刻と一致しないことがある。

新しい音源・リソースパック変更は不要。ビルド、GroundItemEligibilityTest（薬莢・永久待ち・拾得不可・通常品）、AdrenalineHeartbeatRecoveryTest（最後の拍からの全10位相・間隔/音量/ピッチ・終了後の無音）が通過。実クライアントでの縁取りと実際の聴感、死亡・瀕死時の演出切替は確認待ち。
