# PDAのトレーダー選択

既存PDAの端末背景と琥珀色の文字・ツールチップに揃え、中央にKovacs、Pharmakon、Bastion、Brokerの順で連絡先を並べる。ヘッドの説明に取扱品と購入・売却、修理の対応を表示する。下段からPDAへ戻れる。

背景は既存パーティー画面のタイルを使い、ラベルだけをトレーダー用に重ねる。リソースパック・modの追加更新は不要。

## 顔の取得

`TraderDefinition.npcId` でCitizensのNPCを特定する。`SkinTrait` の保存済みテクスチャと署名を優先し、まだ保存されていない場合だけスポーン中のPlayer NPCのプロフィールを見る。NPC番号0も有効。

SkinTraitは依存しているcitizensapiには含まれないため、既にあるTraitの公開 `getTexture` / `getSignature` を参照する。NPCのスポーン・Traitの追加・名前からのスキン照会は行わない。Citizensが無効、NPC未登録、スキン未取得なら従来の購入・売却アイコンへ戻す。

画面を開き直すたびに保存値を読み直す。スキンのテクスチャからヘッドのプロフィールUUIDを決めるため、スキンを変更した後も古い顔を固定しない。

## 操作

一ページは最大7人。追加分は前後のページで選ぶ。表示したスロットとトレーダーの対応で取引画面を開き、並べ替えや余白のクリックで別の相手を開かない。持ち物側からの移動やドラッグも停止する。取引・PDAへの遷移は次tickに行い、既に画面を閉じた場合は遷移しない。

`TraderPortraitsTest` は保存済みスキン、署名、未スポーン、スキン変更、Playerプロフィールへのフォールバック、未登録NPCと番号0を検証する。ゲーム内では各NPCの実際の顔・スキン変更後の再表示・クリック先・PDAへ戻る操作を確認する。
