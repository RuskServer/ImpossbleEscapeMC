# マズルフラッシュの発射信号

発射のたびに `muzzle_flash_*` ポストエフェクトを追加・解除する方式から、常設の `grade` 内で合成する方式へ移す。位置、照り返しの強さ、サプレッサー、深度による手・銃の遮蔽は従来値を使い、炎・にじみの寸法だけを1.2倍にする。

## 送信と消灯

- 発射したtickにモードを送り、次tickに0を送る。1=腰撃ち、2=ADS、3=サプレッサー。
- 更新済みIEM_Compatibilityは `iem:muzzle` の1byteを受け、既存 `IemFrameValues` のVisor.yへ渡す。配列長は変えない。クライアント側でも100msで失効させる。
- modなしでは本人だけに見えるTextDisplayの1文字を使う。専用色(212,123,mode)をtextシェーダーで識別し、既存の制御帯の隣の2画素へ移す。1画素は識別子とモード、もう1画素は描画時刻。太陽光データの形式と容量は変えない。
- 消灯後も通常クライアントのDisplayは再利用する。ワールド移動・死亡・切断・プラグイン停止で回収する。表示されなくなった信号の画素は2tickで失効する。
- 既存の画作りが有効な時に描く。発射でpostEffectsの一覧を変更せず、非発射時は炎・照明計算を行わない。比較用の旧シェーダーはパックに残す。

## 導入と確認

プラグインとリソースパックを同時に更新する。IEM_Compatibilityを使うクライアントはmodも更新する。Toi's Armoryは変更しない。

単発、フルオート、ADS、サプレッサー、明所・暗所・壁際を確認する。銃口の位置、サイズ、銃や手への炎の重なり、射撃停止時の消灯を確認する。modなし／あり双方で行い、ワールド移動・リスポーン後の残像やDisplay残留も調べる。

負荷は同じ視点・銃・射撃時間で旧方式と比較する。平均FPSだけでなく発射時のフレーム時間を見る。新方式は追加の画面描画パスを持たないが、実機での軽量化量は未計測。
