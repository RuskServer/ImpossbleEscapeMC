# 弾の定義威力に統一

プラグイン銃 (プレイヤー・モブ) とデータパック銃の基本ダメージは AmmoDefinition.damage。
GunStats.damage とデータパックのダメージ値・距離減衰・クリティカル倍率はダメージ計算に使わない。
部位はプラグイン銃の着弾位置、データパック銃の CRIT_HIT と弾Markerから判定する。

共通補正: 頭1.2倍、胴・腕1倍、脚0.6倍。非貫通時はさらに0.15倍。
バイザー跳弾はこの計算より前に判定する。成功時はダメージ・負傷なし。
散弾は1粒ごとに定義威力を使う。粒数・射程・発射速度は銃側の設定を維持する。
弾が特定できない旧装備は固定5ダメージ (データパック銃では貫通クラス1)。
弾薬威力の定義値自体は変更していない。

データパックは変更しない。DatapackBulletHitBridge が受けたダメージ値を置き換える。
既存の弾種取得方式も維持: プレイヤーは直近の発射記録、データパック銃SCAVは ScavAmmoSupply。
弾ごとの弾種記録ではないため、着弾前に別弾種へ切り替える場合の混同は残る。

AmmoDamageTest で定義威力、部位、非貫通、散弾1粒、弾不明の計算を確認。
変更した射撃・着弾クラスをコンパイルし、VisorRicochetTest も再実行済み。
実機での威力・バランスは未確認。
