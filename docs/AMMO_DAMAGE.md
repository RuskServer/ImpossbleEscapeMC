# 弾の定義威力に統一

プラグイン銃 (プレイヤー・モブ) とデータパック銃の基本ダメージは AmmoDefinition.damage。
GunStats.damage とデータパックのダメージ値・距離減衰・クリティカル倍率はダメージ計算に使わない。
部位はプラグイン銃の着弾位置、データパック銃の CRIT_HIT と弾Markerから判定する。

共通補正: 頭1.2倍、胴・腕1倍、脚0.6倍。非貫通時はダメージ0 (打撲なし)。
貫通時も防具が威力を殺し、有効な防具クラス1につき10%減らす (クラス3で0.7倍、クラス6で0.4倍)。
有効な防具クラスは耐久値で下がる。満タンで本来のクラス、半分で本来の3/4 (クラス4なら3)、
耐久0で防護なし。式は `round(本来のクラス * (0.5 + 0.5 * 耐久 / 最大耐久))`。
SCAVの防具は最大耐久の30〜50%で生成されるため、はぎ取った物は1クラスほど低い防護になる。
支給品の防具 (45%) も同じ。防具は弾を止めるたびに耐久が減る (止めた弾1発につき `ArmorDurability.BLOCKED_WEAR` = 3)。
貫通された弾や近接・爆発などはバニラの耐久バーが減る。有効クラスは PDC とバーの低い方で決まり、
修理で最大に戻る。耐久0の防具は防護なし。

貫通の確率: 弾クラスが上なら95%、同じなら70%、下なら7.5%。下位クラスの弾だけは
疑似乱数 (PRD、`PenetrationRng`) で引き、外れるほど確率が上がって抜けたら戻る。長期平均は7.5%のまま、
フルオートで「3発続けて抜ける」ような偏りを抑える。連続回数は射手・被害者・頭/胴・防具クラスごとに
覚え、4秒当たらなければ忘れる。
防具は頭がヘルメット、胴がボディアーマー。腕・脚は防具なし (プラグイン銃もデータパック銃と同じ)。
バイザー跳弾はこの計算より前に判定する。成功時はダメージ・負傷なし。
散弾は1粒ごとに定義威力を使う。粒数・射程・発射速度は銃側の設定を維持する。
弾が特定できない旧装備は固定5ダメージ (データパック銃では貫通クラス1)。
弾薬威力の定義値自体は変更していない。

データパックは変更しない。DatapackBulletHitBridge が受けたダメージ値を置き換える。
既存の弾種取得方式も維持: プレイヤーは直近の発射記録、データパック銃SCAVは ScavAmmoSupply。
弾ごとの弾種記録ではないため、着弾前に別弾種へ切り替える場合の混同は残る。

AmmoDamageTest で定義威力、部位、非貫通 (ダメージ0)、耐久による有効クラス、散弾1粒、弾不明の計算を確認。
PenetrationRngTest で下位クラスの確率の上がり方、長期平均、抜けた後の戻り、TTL、頭と胴の分離を確認。
変更した射撃・着弾クラスをコンパイルし、VisorRicochetTest も再実行済み。
防具の耐久が減る量と、実機での威力・バランスは未確認。
