# プレイヤースポーンの配置診断

OP用。プレイヤーのスポーンのみを診断する。SCAVは対象外。

```text
/raid spawn list <mapID> [ページ]
/raid spawn analyze <mapID> [ページ]
/raid spawn add <mapID>
/raid spawn remove <mapID> <地点ID>
/raid spawn clear <mapID>
```

- `list` は省略時に全地点を表示。ページ番号を付けると12地点ずつ表示し、クリックで前後のページ・全地点へ移動できる。60秒以内で配置・ワールド・設定が同じなら診断を再利用する。
- `analyze` は地形を再計算する。建築・遮蔽物変更の後はこれを使う。
- `add` は現在位置を追加し、`remove` は一覧のIDで1地点を削除する。変更後は自動で診断する。
- `clear` は全プレイヤースポーンを削除する。SCAV地点には影響しない。
- IDは削除しても詰め直さず、clear後も再利用しない。旧JSONの`spawnPoints`は残し、`spawnIds`と`nextSpawnId`を追加してロード時に保存する。

## 一覧の意味

一覧の各行は `#地点ID  推定最速秒数 → #相手ID  [判定]`。全地点それぞれについて、相手全員との比較から最も早い推定射線接触時間を表示する。上部にマップ全体の最速ペアと未確定な組数を表示し、再計算ボタンを置く。

座標、直線距離の最寄り地点、100m以内の他地点数、開始時射線の組数、遮蔽と退避方向数、地下候補の根拠、未確定理由は各行のホバーで確認できる。長い未確定理由は8組まで表示する。重量・走行速度・スタミナの前提は目標秒数の行にホバーして確認する。

未計算の組も未確定数に含める。時間が出ていても未確定な相手がいる場合は、より早い接敵があり得る（暫定値）。ワールド未読込などで計算できない時も、全地点の行を残して「未確定」と表示する。

| 推定接触時間 | 初期判定 |
|---|---|
| 開始時射線あり・15秒未満 | 要調整 |
| 15秒以上30秒未満 | 確認推奨 |
| 30〜40秒 | 目標範囲（経路近似） |
| 40秒超 | 早期接敵リスク低め（経路近似） |

足場不正は要調整。退避方向が2方向以下なら確認推奨。

例外として、退避が完全に0方向で、別のスポーン地点が3m以上高く、足場と周囲の検査に問題・未確定箇所がない場合は「地下・立体通路候補」として区別する。根拠の上層地点IDと高低差も表示する。比較は高さ条件を満たす地点のうち最も近い高さを使い、`underground-height-difference`で閾値を変更できる。水平8方向を4m直進する検査では、狭い曲がり角や階段の出口を拾えないことがあるため、退避不足と即断せず出口経路の確認を促す。屋外の低地でも条件に合うので地下確定・安全判定ではない。開始時射線、30秒未満の接敵、経路未確定、足場不正の警告はこの分類で解除しない。

未確定な相手が残る場合、30秒以上という結果だけで問題なしにはしない。開始時の射線が確認できた組は0秒として扱う。

## 計算と限界

- 対象ワールド上で2m格子のA*経路を探索し、各辺を約0.4m間隔で確認する。下向きレイキャストで足場を探し、幅0.6m・高さ1.8mの衝突判定で通行を確認する。上り0.6m、下り約1.2mまで。
- 求めた一経路上を約4m間隔でサンプリングし、両者の到着時刻の大きい方が最小になる、射線の通る位置の組を探す。早く着く側は待機する。単純な距離÷速度や敵地点へ走り切る時間ではない。
- 移動時間は満タン・スキルなしの基準重量（初期値20kg）で計算する。予備スタミナ5を残して歩行へ切り替え、回復開始待ちと満回復まで歩き、再び走る。基本消費4/秒、回復12/秒、回復待ち1秒はStaminaModuleの定数を使い、重量段階の消費・回復待ち、満腹度の回復倍率も反映する。35kg以上はダッシュ不可、40kg超は重量による速度低下を共有の式で反映する。枯渇を避けるペースなので疲労ペナルティは発生しない。休憩量を最適化した厳密な最速戦略ではない。
- 射線は発射側の高さ1.27m・1.62mと、相手の高さ1m・1.27m・1.62mの組を双方向で確認する。方向転換時間、エイム、実際の銃の射程は計算しない。
- **別ルートも含めた厳密な最速接敵ではない。** 狭い通路、ジャンプ、はしご、水泳、扉を開ける操作、破壊可能な壁、スキル・興奮剤・ジャンプ消費・任意の休憩配分は未評価。重量とスタミナは上記の固定条件で評価する。速い射線が発見できれば危険の根拠になるが、遅い結果は安全の保証にならない。
- 遮蔽は8方向の8m射線が塞がる方向数、退避は8方向へ4m歩ける方向数。実際の戦闘中の安全や敵の位置までは評価しない。
- 全スポーンを囲む矩形に余白32mを足した範囲を非同期読込する。初期上限2048チャンク、同時読込2チャンク。総数超過なら診断を開始せず設定調整を案内する。同時診断は2マップまで。
- 既存チャンクのみを読み、未生成チャンクは生成しない。読込失敗・範囲外は未確定にする。射線が通るチャンクを境界ごとに確認する。ワールド自体が未読込なら座標だけを表示する。
- 読込後は診断終了までChunkLeaseで保持し、成功・時間切れ・中断・エラー・プレイヤー切断・プラグイン停止で解除する。非同期処理が中断後に完了しても保持は追加しない。SCAVの保持と参照数を共有し、元からある外部のプラグインチケットは解除しない。
- 上限、経路なし、読込失敗・範囲外、時間切れは未確定として理由を出す。64地点超は座標一覧のみ。
- 最大64地点の全組み合わせ（2016組）を対象にする。旧 `max-pairs` 設定は使わない。全ペアの開始時射線を先に検査し、射線がないペアの経路を順に探索する。比較順は各地点が早い段階で参加するラウンド方式とし、地点IDの後半だけが後回しになる偏りを抑える。制限時間に達した未完了の組は省略せず未確定にする。
- メインスレッドで少しずつ検査する。全マップの診断でtickごとの時間予算を共有する（単一API呼び出しの実行時間は途中で打ち切れない）。診断中に配置やワールドが変われば結果を破棄する。

`config.yml` の `raid-spawn-diagnostics` で速度、基準重量、満腹度、予備スタミナ、判定秒数、チャンク読込上限、探索上限とtick予算を変更できる。走行5.6m/s・歩行4.3m/sは計算上の基準値なので、実際の軽装時の移動速度に合わせて調整する。

## 検証

`SpawnDiagnosticsTest` のmainで、旧JSON移行、削除と再読込後のID維持、ID再利用防止、壁の迂回、経路不成立・探索上限、接触時刻の計算と判定境界を検証する。実ワールドでの段差・窓・複層通路の精度と負荷はゲーム内で確認する。

`SpawnChunkLoaderTest` は非同期完了・未生成・例外・中断後の完了・チケット共有と上限を、`StaminaTravelModelTest` は短距離走行・長距離回復・重量・満腹度・ダッシュ禁止・周期境界を検証する。

`SpawnContactSummaryTest` は0〜64地点の全ペア網羅・重複防止・早期の全地点参加、最速相手の集計、未計算／経路失敗／暫定結果の数え方を検証する。
