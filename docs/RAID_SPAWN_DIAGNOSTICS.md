# プレイヤースポーンの配置診断

OP用。プレイヤーのスポーンのみを診断する。SCAVは対象外。

```text
/raid spawn list <mapID> [ページ]
/raid spawn analyze <mapID> [ページ]
/raid spawn add <mapID>
/raid spawn remove <mapID> <地点ID>
/raid spawn clear <mapID>
```

- `list` は6地点ずつ表示。60秒以内で配置・ワールド・設定が同じなら診断を再利用する。
- `analyze` は地形を再計算する。建築・遮蔽物変更の後はこれを使う。
- `add` は現在位置を追加し、`remove` は一覧のIDで1地点を削除する。変更後は自動で診断する。
- `clear` は全プレイヤースポーンを削除する。SCAV地点には影響しない。
- IDは削除しても詰め直さず、clear後も再利用しない。旧JSONの`spawnPoints`は残し、`spawnIds`と`nextSpawnId`を追加してロード時に保存する。

## 一覧の意味

直線距離の最寄り地点、100m以内の他地点数、開始時に射線の通る組数、経路上の推定最短射線接触時間、遮蔽と退避方向数を表示する。

| 推定接触時間 | 初期判定 |
|---|---|
| 開始時射線あり・15秒未満 | 要調整 |
| 15秒以上30秒未満 | 確認推奨 |
| 30〜40秒 | 目標範囲（経路近似） |
| 40秒超 | 早期接敵リスク低め（経路近似） |

足場不正は要調整。退避方向が2方向以下なら確認推奨。未確定な相手が残る場合、30秒以上という結果だけで問題なしにはしない。開始時の射線が確認できた組は0秒として扱う。

## 計算と限界

- 対象ワールド上で2m格子のA*経路を探索し、各辺を約0.4m間隔で確認する。下向きレイキャストで足場を探し、幅0.6m・高さ1.8mの衝突判定で通行を確認する。上り0.6m、下り約1.2mまで。
- 求めた一経路上を約4m間隔でサンプリングし、両者の到着時刻の大きい方が最小になる、射線の通る位置の組を探す。早く着く側は待機する。単純な距離÷速度や敵地点へ走り切る時間ではない。
- 射線は発射側の高さ1.27m・1.62mと、相手の高さ1m・1.27m・1.62mの組を双方向で確認する。方向転換時間、エイム、実際の銃の射程は計算しない。
- **別ルートも含めた厳密な最速接敵ではない。** 狭い通路、ジャンプ、はしご、水泳、扉を開ける操作、破壊可能な壁、重量・スキル・スタミナは未評価。速い射線が発見できれば危険の根拠になるが、遅い結果は安全の保証にならない。
- 遮蔽は8方向の8m射線が塞がる方向数、退避は8方向へ4m歩ける方向数。実際の戦闘中の安全や敵の位置までは評価しない。
- 未読込チャンクを強制ロードしない。射線が通るチャンクを境界ごとに確認する。ワールド未読込なら座標だけを表示する。
- 上限、経路なし、未読込、時間切れは未確定として理由を出す。64地点超は座標一覧のみ。
- メインスレッドで少しずつ検査する。全マップの診断でtickごとの時間予算を共有する（単一API呼び出しの実行時間は途中で打ち切れない）。診断中に配置やワールドが変われば結果を破棄する。

`config.yml` の `raid-spawn-diagnostics` で速度、判定秒数、探索上限とtick予算を変更できる。速度の初期値5.6m/sは計算上の基準値なので、実際の軽装時の移動速度に合わせて調整する。

## 検証

`SpawnDiagnosticsTest` のmainで、旧JSON移行、削除と再読込後のID維持、ID再利用防止、壁の迂回、経路不成立・探索上限、接触時刻の計算と判定境界を検証する。実ワールドでの段差・窓・複層通路の精度と負荷はゲーム内で確認する。
