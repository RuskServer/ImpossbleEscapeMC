# SCAV救援の交戦単位上限

救援の受諾総数を交戦全体で2体までに制限する。
`ScavHelpEncounter` はUUIDだけを保持し、サーバースレッド上で扱う。

- 救援を引き受けた時点で枠を消費し、交戦グループを継承する。
- 救援SCAVが接敵して自分も救援を呼んでも、継承した枠を使う。
- 同じ敵UUIDに独立して接敵したSCAVも同じ枠を使う。
- 接敵・離脱・死亡で枠を返さない。交戦中の補充による増員を防ぐ。
- 既に救援中の個体は、枠を追加消費せず呼び直して救援時間を更新する。
- 敵の切り替えでも継続中の交戦枠を保持する。
- グループの最後の接敵/被弾から200tick（20TPSで10秒）経過したら終了し、次の交戦で枠を新設する。

直接敵を見つけて戦っている個体は救援枠に数えない。
別々の交戦が合流した場合は消費済み枠を合算して以後の招集を止める。
合流前に受諾済みの救援は取り消さないので、その場合に既存救援が2体を超えることはある。
敵位置を味方へ通知する処理は追加していない。

## 検証

`ScavHelpEncounterTest` をJavaコンパイラでコンパイルしmainを実行。
上限、呼び直し、救援からの連鎖、独立接敵、枠維持、失効境界、新交戦、
敵切り替え、交戦合流、攻撃者不明のケースを確認した。
ScavController/ScavSquad/ScavHelpEncounterはPaper依存下でコンパイル確認済み。
ゲームサーバーでの実行確認と配布は未実施。
