# PDA ホーム

従来の27枠チェストGUIとPDA背景を使用する。リソースパックの追加更新は不要。

## ホームと隠れ家の選択画面

ホームの主要スロットは従来と同じ。4にプレイヤーヘッド、9にHideout、10にパーティー、11に倉庫、12に市場、13に統計、14に出撃、15に商人、16にタスク、17に銃の設定、22に閉じるを配置する。26は情報更新。

Hideoutを押すと、別の27枠チェストで次の2択を表示する。この時点では移動しない。

| スロット（0始まり） | 操作 |
| --- | --- |
| 11 | 隠れ家へ移動。隠れ家にいる場合はロビーへ戻る |
| 15 | 設備管理。既存の設置・アップグレード画面を開く |
| 22 | PDAへ戻る |

左右どちらの選択も通常クリックで実行できる。設備のアップグレード画面自体は変更しない。
既存の背景素材に移動・設備管理・戻るの文字を重ねる。アイテム名は「名前 ｜ 用途」、利用不可の場合は「名前 ｜ 理由」に統一する。
チェストの仕様上、アイテム名と説明はカーソルを合わせて読む。
レイド中はHideout入口と両選択肢を利用不可にする。ほかの既存のレイド制限と市場Lv.10解放も維持する。

## 実装と保護

`PDAGUI` のconstructor/openを維持する。表示・利用条件を`PdaHomeModel`、操作の受付を`PdaHomeController`、チェストと既存の行き先への接続を`PdaHomeScreen`が担当する。
ホームと隠れ家選択それぞれにプレイヤーごとの一度限りの識別子を使う。各ページに存在する操作だけ受け付け、操作の次tickでも同じ画面を開いている場合だけ実行する。
古い画面・二重操作を拒否し、実行直前にレイド状態・現在地・レベル・利用可否を再取得する。
表示中のクリックによるアイテム移動と上段へのドラッグを拒否する。
画面を閉じた場合・切断・死亡で登録を破棄し、停止時には開いているホームとリスナーを解放する。

## 確認

`PdaHomeTest`で従来スロット、隠れ家選択の2択と戻る、入口では移動しないこと、ページ外操作の拒否、レイド・市場制限、現在地変更、古い操作・二重操作、既存の行き先と終了処理を確認する。
実機ではPDA背景のラベル位置、数字キー・Shift移動・ドラッグの拒否、別GUIへの遷移と隠れ家の往復を確認する。
