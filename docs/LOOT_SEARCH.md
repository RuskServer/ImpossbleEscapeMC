# レアリティ別のルートサーチ

検索開始時の品物を、既存の発見音・衝撃波と同じレアリティ判定で分類する。通常品・弾薬・アタッチメントのカタログを参照し、不明な物はコモンとして扱う。

| レアリティ | 基本tick | 基本時間（20TPS） |
| --- | ---: | ---: |
| コモン | 10 | 0.5秒 |
| アンコモン | 12 | 0.6秒 |
| レア | 15 | 0.75秒 |
| エピック | 20 | 1.0秒 |
| レジェンダリー | 26 | 1.3秒 |

既存の`SEARCH_TICKS`スキル補正を加算する。各探索ノードの-1tickは従来どおりで、最短1tick。
エピックとレジェンダリーは、短縮後の時間の50%（端数切り上げ）から3tickでリングの色を変える。エピックは既存の衝撃波と同じ紫、レジェンダリーは同じ橙。先端も明るい色へ変える。コモンからレアまでと、検索前半は従来の琥珀色を使う。

リングの回転は8フレームのまま。背景・枠・未確認の「?」は着色しない。アイテム本体、発見イベント、発見音、四角い衝撃波は検索完了時に出す。予告段階に効果音やアイテム名を追加しない。

検索中に同じ品の残数が変わるだけなら継続する。品物の種類・メタデータが変わった場合や消失した場合は検索を中断し、別の品へ時間や予告色を引き継がない。画面を閉じた時は従来どおり中断し、未完了の進捗は保存しない。完了済みスロットの記録・共有インベントリ・FIR・部分取得と保存処理は従来のまま。

## パックとの対応

`tools/search_gui.py`で通常の8モデルを背景・リング本体・先端の3レイヤーへ分ける。背景は固定の白色tint、リングは`custom_model_data.colors[0]`、先端は`colors[1]`を使う。色はプラグインが検索フレームごとに送る。

モデルIDは従来の`iem:search/spin_0`〜`spin_7`を維持する。新パックで旧プラグインを使う場合、既定色で従来のアイコンを再現する。旧パックで新プラグインを使った場合、時間は変わるが予告色は反映されない。色の演出にはプラグインとパックの両方を更新する。modとデータパックの変更は不要。

## 確認

`LootSearchAnimationTest`で時間、スキル補正後の中間点、3tickの色遷移、回転、品物の差し替え判定を確認する。`tools/check_search_gui.py`は8モデルのレイヤーとtint参照、従来色の画素一致、着色時の背景不変を確認する。
実機では各レアリティ、探索スキルの有無、複数枠の同時検索、閉じて開き直す操作、複数人で同じ品を検索・取得する場合、バックパック表示切替、完了時の音と衝撃波を確認する。
