# 銃弾の腕・胴判定

## 入射点だけの判定による偏り

データパック銃の着弾は、弾Markerの方向から拡張AABBへの入射点を逆算する。従来は胴の高さで、入射点が体の左右中心から幅の30%を超えると腕としていた。

幅0.6の対象で拡張幅0.1の場合、胴中心へ向かう弾でも、正面から30度の入射点は左右約0.231となる。腕の閾値0.18を超えるため、胴へ向かう弾が腕扱いになっていた。

通常の胴防具が腕を防護しないこと、腕のダメージ倍率が胴と同じであることと重なり、胴への射線で防具が適用されないケースが生じていた。

## 現行の弾道付き判定

1. 頭・顔・脚・胴の既存の入射点判定は維持する。
2. 従来なら腕となる命中について、体の向きへ変換した弾道が胴の中心領域を横切るか確認する。
3. 横切る場合は胴、外周だけを通る場合は腕として、既存の防具・ダメージ計算へ渡す。
4. 方向を復元できない場合、胴の高さの外周点だけを根拠に腕の無防護を適用せず、胴扱いへ戻す。

胴の中心領域は体の向きに追従する箱。左右半径は対象の幅の30%、前後半径は25%、高さは既存の脚境界から頭境界までとする。判定には接触点から進行方向への前向きの射線だけを使い、後方へ延長して胴を拾わない。

これは人体モデルの腕・胴を別々に貫通させる物理計算ではない。1発につき既存の部位を一つだけ選び、腕と胴へ二重にダメージを与えない。

SCAVとプレイヤーのデータパック銃で共通に適用する。SCAVの照準、弾の威力、部位倍率、防具の防護範囲、貫通抽選、散弾の粒数処理は変更しない。頭・顔の倍率はデータパックのCRIT_HITがある場合だけ適用し、バイザー跳弾に渡す入射方向は維持する。

## 検証

`BallisticArmHitTest` は、負座標を含む位置・体の向き・入射角・立ち／しゃがみ相当の目の高さ・幅を変えた864本の胴中心射線を確認する。外周だけの腕命中、進行方向が不明な場合、前向き射線、入力ベクトル非破壊、実ブリッジへの方向受け渡し、頭・顔・脚の保持も検証する。

実サーバーでは、胴防具を着けて正面・斜め・側面から被弾し、部位記録と防具の適用を確認する。姿勢・装備・通信遅延による実際の命中分布は、実地での確認が必要。


## 発射情報と重複命中

弾Markerの追加イベントで、召喚NBTの `toisarm.bullet` と `BULLET_INIT` を確認する。この時点ではデータパックのowner転記がまだ済んでいないため、処理中の `PLAYER` タグと `#id _` / `toisarm.id` を照合して射手を特定する。距離で近くの射手を選ばない。

装填弾の威力・貫通クラス・射手の実体UUID・粒数をMarkerのPDCへ一度だけ保存する。SCAVは発射時点の供給弾を使う。着弾時に射手の手持ちや最後の発射記録を読み直さないため、同tickの初弾、持ち替え、次の射撃、弾薬定義の変更で発射済みの弾が変わらない。発射情報のない更新前の弾だけは従来の不明弾相当（威力5・クラス1、散弾はMarkerの粒数で分割）を使う。

同じMarkerから同じ実体UUIDへの命中は一度だけ処理する。SCAV本体への直接命中とFakePlayerからの転送も同じ対象とする。本体にHITタグがある時は直接の命中イベントを優先し、FakePlayer側のCRIT_HITやイベント順序を判定に持ち込まない。別々の散弾Markerと別の貫通先は独立して処理する。防具による阻止・バイザー跳弾も、その弾の一度の命中に含める。

## 防具耐久

被弾部位を防護する防具のうち、貫通計算に使った一着だけを手動消耗させる。プレイヤーとSCAVで同じ規則を使い、無防護の腕・脚への命中でヘルメットやベストを削らない。

- 阻止した弾：従来どおり耐久3を消費する。
- 貫通した弾：正の最終ダメージに対して `max(1, floor(damage / 4))` を消費する。ゼロなら消費しない。
- プレイヤーのバニラ側の全スロット消耗は、処理済みの銃弾イベントと同じtick・同じlastDamageCauseの防具ダメージだけを取り消す。道具の耐久消費、別原因による被弾、後のtickの耐久消費は維持する。
- 耐久はPDCと表示バーを既存の `ArmorDurability.wear` で同時に更新する。

`DatapackDamageRegressionTest` は発射時の保存、通常弾の同tick初弾、後の弾薬変更との分離、散弾の理論総量、別対象、入れ子のイベント、同一弾の重複抑止、防具耐久イベントの限定を検証する。`BallisticArmHitTest` はCRIT_HITなしの顔面が胴扱いになることも検証する。
